DAY 01 · 아키하바라지도 · Google Maps
Day 01 이동 순서

정류장과 이동 수단을 함께 확인하세요.

노선 색은 날짜를, 실선은 도보, 점선은 대중교통을 의미합니다. 기본 연결선은 개략 직선입니다. 「실제 경로」를 켜면 Google Routes API로 계산한 경로를 지도 안에 표시합니다(요금이 발생할 수 있음). 전철 시간은 여행 당일의 확정 시간표가 아닌 조회 시점 기준입니다. 호텔을 바꾸더라도 일정표의 시간 추정치는 기본 호텔 기준입니다.

Google Maps에서 이 날의 경로 보기
Google Maps API 설정 · 인터랙티브 지도
이 HTML에 Google Maps JavaScript API를 직접 연결합니다. Google Cloud API 키는 이 페이지에 입력하거나 소스의 GOOGLE_MAPS_API_KEY 상수에 지정하세요. 지도 핀·이동선은 키 연결 후 페이지 안에서 작동하고, 실제 도보·전철 경로에는 Routes API를 사용합니다. Google Cloud에서 브라우저 키 발급 ↗ · 결제 계정 및 Maps JavaScript API 활성화 필요 · 실제 경로 옵션은 Routes API도 활성화하세요. 키는 브라우저 세션에만 저장되며 공개 채팅으로 전송하지 않습니다. 배포 시 HTTP referrer 및 API별 사용 제한을 설정하세요.

API 키 연결 전에는 Google 지도가 미리보기로 표시됩니다. 사용자 지정 핀·이동선은 API 연결 후 활성화됩니다.
